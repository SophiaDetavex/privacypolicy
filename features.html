Features · A0000007

Project Milepost features.

A local-first milestone tracker for personal dates, anniversaries, deadlines, goals, memories, bundled history content, local event photos, Calendar import, and a single-event Home Screen widget.

Local-first recordsCalendar import optionalLocal event photosCompact banner ads

Milestone timelines

Track events as cards, grids, and timelines with count-up and countdown information.

Calendar import

Import selected Calendar events only when the user chooses that workflow.

Local event photos

Selected photos can become local event imagery and widget backgrounds without deleting the original photo-provider file.

Single-event widget

The Home Screen widget displays one local milestone snapshot and does not include advertising, purchases, tracking code, or network behavior.
