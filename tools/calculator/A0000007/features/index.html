Product information · A0000007

Project Milepost features

Private milestone planning, countdowns, photos, calendar actions, and widgets.

Local-firstUser-controllediPhone and iPad

Core capabilities

  • Milestone creation, countdowns/count-ups, recurrence, categories, notes, completion tracking, and local search.
  • Optional photos and Calendar integration initiated by the user.
  • Home-screen widgets using a shared app-group snapshot.
  • Consent-aware compact top banner advertising in the free release.

Release boundaries

  • No Project Milepost account or developer-hosted milestone cloud is required.
  • Milestone text and selected photos are not supplied to Google for ad targeting through the app's integration.
  • The app does not provide public profiles, messaging, or a social feed.
  • Calendar and photo access are not used before the user grants the relevant permission or chooses an item.

Version authority

Source-aligned review completed against Project Milepost 1.9.2 build 68.
