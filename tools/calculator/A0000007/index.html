Project IDA0000007

PlatformiPhone and iPad
Privacy postureProject Milepost keeps milestone records and selected media locally or in its shared app-group container, accesses Calendar and Photos only when chosen, and integrates one consent-gated Google AdMob banner using Google Limited Ads without Apple-defined cross-app tracking.
AdvertisingThe free release integrates one Google AdMob banner with Google UMP consent handling. Build 68 forces Google Limited Ads before SDK startup, disables publisher personalization, publisher first-party ID, and Google Mobile Ads SDK exception reporting, and blocks ad requests unless the current configuration and consent state are eligible.
PurchasesNo account is required. No purchase is required for the disclosed milestone workflows in this source package.
PermissionsCalendar/full calendar access: optional import or export of milestone events after an explicit system grant. Photo Library: optional user-selected milestone imagery after an explicit system grant or picker action.
Audit provenanceSource-aligned review completed against Project Milepost 1.9.2 build 68.
