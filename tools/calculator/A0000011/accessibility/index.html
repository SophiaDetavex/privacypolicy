Accessibility · A0000011

Accessibility in Great Chess

Published accessibility commitments and alternatives for the reviewed release.

VoiceOverDynamic TypeNon-color cuesReduce Motion

Supported design practices

  • VoiceOver labels for board squares, pieces, moves, menus, controls, and game status.
  • A fully interactive 2D board alternative to the visual 3D scene.
  • Dynamic Type-aware menus and settings, non-color board/status cues, and Reduce Motion considerations.
  • Haptic and audio feedback supplement visible/textual game state rather than replacing it.

Report an accessibility barrier

Email trentshurts@gmail.com with the feature, assistive technology, device, OS version, and steps. Do not include private app content unless necessary and redacted.

Release testing requirement

Source review cannot replace testing the signed build with VoiceOver, Switch Control, Voice Control, Full Keyboard Access, Dynamic Type, contrast settings, and Reduce Motion on supported devices.
