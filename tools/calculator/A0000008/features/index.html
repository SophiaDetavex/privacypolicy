Structured workspace

Notebook, section, note, document, code-note, mind-map, whiteboard, and imported-file workflows.

Document import

Open user-selected Project Scribe, TXT, PDF, image, DOCX, and supported raster files through Apple document pickers.

Photo/image import

Use Apple’s privacy-preserving PHPicker flow for selected images without broad photo-library permission.

Autosave and local persistence

Workspace snapshots and user content are stored locally so work remains available between launches.

Diagnostics and syntax checks

Local validation helps detect common code or document issues without sending workspace content to a developer server.

Dormant monetization path

Advertising and Remove Ads purchase code paths are disabled by default until production identifiers, App Store products, consent flows, and disclosures are ready.
