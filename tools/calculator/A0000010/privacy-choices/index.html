Privacy Choices · A0000010

Privacy choices for Project Calibrate.

The controls below use the same structure for every app subsection so users can quickly understand what can be changed, deleted, avoided, or reported.

Local data

  • Use only tools you want to use; permission-gated tools can be denied or disabled through iOS settings.
  • Delete the app to remove app-local preferences, calibration, favorites, and cache data, subject to normal iOS backup behavior.
  • Avoid the Currency tool if you do not want a reference-rate network request.

Network and services

  • When Currency is opened or refreshed, the app requests the latest reference-rate table from the disclosed Frankfurter endpoint; selected pairs and entered amounts are not included in that request.
  • Apple system permissions may provide live camera, microphone, motion, heading, magnetic, torch, and light-related sensor inputs only while relevant tools are active.
  • Support email and ordinary website server logs are handled by the relevant email and hosting providers.

Advertising posture

Build 43 keeps Google AdMob dormant: no Google advertising packages, AdMob identifiers, banner requests, or UMP forms are present.

Support contact

Email trentshurts@gmail.com with privacy questions.
