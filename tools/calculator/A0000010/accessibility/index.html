Accessibility for Project Calibrate.

This subsection uses a consistent accessibility layout for every app and records the support channel for reporting accessibility barriers.

Supported platform expectations

Project Calibrate is intended for iPhone and iPad. Interface behavior should be reviewed with Dynamic Type, VoiceOver, Reduce Motion, light/dark appearance, and common device sizes before release.

Report an issue

Email trentshurts@gmail.com with the screen, control, assistive technology, device, and iOS/iPadOS version involved.

Privacy while reporting

Do not include sensitive screenshots or personal content unless it is necessary and you are comfortable sending it by email.

Release checkpoint

Accessibility claims should be retested before release whenever navigation, controls, text sizing, color, animation, or game/utility layouts change.
