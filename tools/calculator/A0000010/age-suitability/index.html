Age suitability · A0000010

Age suitability for Project Calibrate

A content profile supporting App Store age-rating review; the App Store rating remains controlled by the submitted questionnaire and binary.

No public chatNo real-money wageringNo unrestricted browsing

Content profile

  • The app supplies utility and sensor tools rather than public communication or mature entertainment content.
  • It does not include gambling, public user-generated content, matchmaking, or unrestricted browsing.
  • Final App Store age-rating answers must match the submitted binary and current Apple questionnaire.

Privacy and permissions

Project Calibrate stores settings and calibration state locally, accesses camera, microphone, and motion sensors only for user-invoked tools, optionally retrieves currency reference rates, and integrates a consent-aware Google AdMob banner.

  • Camera: on-demand visual measurement, level, or light-related tools after an explicit system grant.
  • Microphone: on-demand sound-related measurement tools after an explicit system grant.
  • Motion: on-demand orientation, level, or movement tools after an explicit system grant.

Parents and guardians

Use Apple family, purchase, permission, and Screen Time controls appropriate for the device user. Service-provider consent and advertising controls, where present, may differ by region.
