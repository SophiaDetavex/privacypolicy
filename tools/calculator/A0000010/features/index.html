Product information · A0000010

Project Calibrate features

Calibrate everyday measurements with focused local tools and on-demand sensors.

Local-firstUser-controllediPhone and iPad

Core capabilities

  • Conversion, calibration, dimensional, orientation, light, sound, camera, and reference tools.
  • Local-first settings and measurement workflows with permissions requested only in context.
  • Optional currency reference retrieval.
  • Consent-aware Google AdMob banner advertising in the free release.

Release boundaries

  • No Project Calibrate account or developer-operated measurement cloud is required.
  • Raw camera, microphone, or motion streams are not supplied to Google for advertising through the app's integration.
  • Sensors are not accessed before the user invokes a relevant tool and grants permission.
  • The app does not itself request App Tracking Transparency permission in the audited source package.

Version authority
