Release profile

Project IDA0000010
Version0.1.7 (44)
PlatformiPhone and iPad
Privacy postureProject Calibrate stores settings and calibration state locally, accesses camera, microphone, and motion sensors only for user-invoked tools, optionally retrieves currency reference rates, and integrates a consent-aware Google AdMob banner.
AdvertisingBuild 44 integrates one compact Google AdMob banner in a top, centered normal-flow lane and Google UMP consent flow. Invalid, demonstration, blank, or cross-publisher identifiers fail closed; the initial layout is stable while consent is unresolved; and the banner lane collapses after a definitive block or revocation.
PurchasesNo account is required. No purchase is required for the disclosed calibration and conversion workflows in this source package.
PermissionsCamera: on-demand visual measurement, level, or light-related tools after an explicit system grant. Microphone: on-demand sound-related measurement tools after an explicit system grant. Motion: on-demand orientation, level, or movement tools after an explicit system grant.
Audit provenanceSource-aligned review completed against Project Calibrate 0.1.7 build 44.
