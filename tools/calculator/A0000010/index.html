Privacy PolicySupportFeatures
Local-first utilitySensors on demandCurrency rates disclosedAdMob dormant

Unit conversion

Physical and domain-specific conversions use explicit factors, domain checks, and provenance labels. Medical, diagnostic, dosing, treatment, and blood-glucose conversion categories are excluded in Build 43.

Sensor and camera tools

Camera, microphone, motion, heading, torch, magnetic, and light-related workflows run only while the relevant tool is open and permissions allow access.

Currency reference rates

Currency requests obtain a reference-rate table; selected pairs and entered amounts are not sent by the app as request parameters.

Dormant advertising state

Build 43 does not link Google advertising or UMP packages, does not include AdMob identifiers, and does not request advertising consent forms.

Privacy snapshot

What users should understand first.

Project Calibrate stores preferences and calibration locally, uses hardware permissions only for active tools, requests a currency reference table when needed, and keeps Google AdMob dormant in Build 43.
