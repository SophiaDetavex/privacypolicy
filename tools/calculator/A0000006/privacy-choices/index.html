Controls

Manage data and permissions from the right place.

Some controls live inside the app, some live in iOS Settings, and support-record requests are handled through email.

Clear local history

Use the in-app history controls to remove saved calculations.

Control camera access

Use iOS Settings to grant or revoke Camera permission. You can avoid Photo input and still use the core calculator.

Control microphone and speech recognition

Use iOS Settings to grant or revoke Microphone and Speech Recognition permissions. You can avoid Voice Math and still use the core calculator.

Avoid live exchange-rate requests

Do not use the optional live Money calculator lookup path.

Remove local app data

Delete the app to remove app-local data managed by iOS, subject to ordinary operating-system behavior.

Request support or deletion help

Email trentshurts@gmail.com for privacy questions or support-record deletion requests.

Deletion requests

Most app content for this package is local to the device, so the developer generally cannot see or delete it remotely. For support emails or records you sent directly to support, email trentshurts@gmail.com and identify the support conversation you want reviewed.

Advertising release posture

The current release does not request or display ads. The prepared Google AdMob path is disabled and remains unavailable in the default app target unless a future release updates the app, App Store privacy labels, and this public policy branch.
