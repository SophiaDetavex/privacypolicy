Great Calculator features.

A free calculator suite with everyday math, scientific workflows, graphing, geometry, unit conversion, finance helpers, time tools, local history, and optional live exchange-rate lookup.

Local-first calculator dataGoogle AdMob + UMP disclosedNo account requiredOptional rate lookup

Everyday and advanced calculation

Standard, scientific, fraction, percentage, geometry, graphing, permutation, number, finance, and time workflows are gathered into one touch-first interface.

Local history and preferences

Committed calculator history and display preferences stay on device so the app can restore recent work between launches.

Optional live currency rates

Live exchange-rate lookup is used only when the user requests currency conversion; entered amounts are processed locally after a rate returns.

Ad-supported free release

The free release discloses Google Mobile Ads and Google User Messaging Platform behavior for banner advertising and consent where applicable.
