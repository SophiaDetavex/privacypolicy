Age Suitability

Age-suitability context for Project Game Room.

Project Game Room is a local mini-game collection. The current package does not include public chat, public multiplayer, gambling, real-money gaming, user-generated public feeds, location tracking, or active ads. App Store age-rating answers should still be completed for the exact submitted binary and any future content changes.
